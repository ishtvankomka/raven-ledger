# Shared secret patterns — ONE list, used by every gate in this repo.
#
# Consumers (all read this file; none keep their own copy):
#   sync/lib.sh                          looks_secret()  — capture + pre-commit gate
#   library/hooks/scripts/pre-bash-guard.sh              — staged-diff gate (fallback
#                                                          when gitleaks is absent)
#   library/guardrails/secret-scanner.md                 — the agent's scan list
#
# Format: one POSIX ERE per line, consumed with `grep -Ef` (case-insensitive).
# Blank lines and #-comments are stripped by the caller before use.
#
# Design: prefer a vendor prefix (near-zero false positives) over a generic shape.
# Generic rules require a long unbroken value so prose cannot trip them. This list
# is the FALLBACK — when gitleaks or trufflehog is installed, the callers use that
# instead, because a bespoke regex will always trail a maintained ruleset.

# --- generic shapes --------------------------------------------------------
# A long value assigned to a secret-shaped identifier. The keyword may sit
# ANYWHERE in the identifier — AWS_SECRET_ACCESS_KEY= is why. The value class
# excludes '-' and '.' so hyphenated prose cannot match.
[A-Za-z0-9_.-]*(secret|token|passw(or)?d|api[_-]?key|access[_-]?key|private[_-]?key|credential|client[_-]?id)[A-Za-z0-9_.-]*["']?[[:space:]]*[:=][[:space:]]*["']?[A-Za-z0-9_/+=]{16,}

# A long hex value assigned to an auth-shaped identifier (Twilio-style).
(auth|secret|token|key)[A-Za-z0-9_.-]*["']?[[:space:]]*[:=][[:space:]]*["']?[A-Fa-f0-9]{32,}

# Credentials embedded in a connection URL. The password must contain a digit,
# which keeps documentation placeholders like postgres://user:password@host out.
://[A-Za-z0-9_.%+-]{2,}:[A-Za-z0-9_.%+-]*[0-9][A-Za-z0-9_.%+-]{5,}@
